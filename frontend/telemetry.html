Примеры подключения API

Все примеры получают актуальный снимок. Адрес локальный и доступен в пределах запущенного сервера.

JavaScript
const response = await fetch('/api/system/stats');
const telemetry = await response.json();
console.log(telemetry.cpu, telemetry.gpu, telemetry.processes);
Python
import urllib.request, json
url = 'http://127.0.0.1:8765/api/system/stats'
with urllib.request.urlopen(url, timeout=5) as r:
    telemetry = json.load(r)
print(telemetry['cpu'], telemetry['gpu'])
PowerShell
$telemetry = Invoke-RestMethod 'http://127.0.0.1:8765/api/system/stats'
$telemetry.cpu
$telemetry.gpu
$telemetry.unavailableParameters
