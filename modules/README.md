# Каталог модулей PQlocalAgentOSv3

Эта папка предназначена для локальных модулей и их манифестов. Каждый модуль располагается в отдельной папке и описывает себя в `module.json`.

## Контракт модуля

Минимальный манифест должен содержать `id`, `name`, `version`, `description` и `api_version`. Поля `inputs`, `outputs`, `capabilities` и `permissions` описывают совместимость и необходимые полномочия.

- Модули не должны напрямую изменять ядро приложения.
- Связи между модулями объявляются отдельно и должны проверять типы входов и выходов.
- Внешний код не запускается автоматически после добавления репозитория.
- Перед запуском необходимы проверка исходников, лицензии, зависимостей и разрешений, а также изоляция выполнения.
- Не помещайте токены, пароли и другие секреты в манифесты.

Реестр подключённых к текущему локальному экземпляру модулей хранится в `data/modules.json`; этот файл не коммитится. Манифесты установленных модулей создаются в подпапках этой директории.
