# Обзор проекта
> PQlocalAgentOSv3 — локальное приложение для настройки AI-агентов, проектов, модулей и интерфейса.
> Сервер запускается в Windows через `start.bat` и по умолчанию слушает `127.0.0.1:8765`.
> В чате есть отдельный runtime событий, файловый журнал и потоковая доставка SSE.
> Это альфа: наличие интерфейса или API ещё не означает, что все сценарии завершены.
> Перед выводами о готовности сверяй исходники и тесты из `tests/`.

## Цель
Создать локальную среду, в которой пользователь управляет агентами, проектами, моделями, модулями и интерфейсом, а ход чат-агента представлен последовательностью наблюдаемых событий.

## Для кого
Разработчики и технические пользователи, которым нужен контролируемый локальный интерфейс к моделям и инструментам и возможность проверять ход выполнения.

## Принципы
1. **Локальный контроль:** HTTP-сервер по умолчанию привязан к loopback; это не означает, что каждый провайдер или интеграция работает без сети.
2. **Проверяемость:** события чата сохраняются до публикации; терминальные статусы должны согласовываться с runtime-контрактом и тестами.
3. **Ограничение побочных эффектов:** инструменты используют разрешения и проверку разрешённых корней.
4. **Прозрачность:** состояние хода, вызовы инструментов, результаты и запросы подтверждения представлены событиями.
5. **Модульность:** сервер, runtime чата, провайдер и frontend разделены на отдельные модули.

## Границы и не-цели
- Не считать текущий чат универсальным адаптером всех провайдеров: `server.py` отклоняет потоковый чат, если формат провайдера не Ollama.
- Не считать приложение многопользовательским production-сервисом.
- Не заявлять sandbox для инструментов, полную мультимодальность или отказоустойчивый multi-process журнал без соответствующей реализации.
- Не считать `cancel_task` доказательством завершённого UX отмены во всех состояниях.

## Статус
**Альфа / активная разработка.** Ориентир 50–60% можно использовать только как грубую продуктовую оценку, не как измеренную метрику тестов. Конкретные проценты зависят от определённых критериев готовности; см. внешний Build-in-Public материал.
