# Основной frontend и конструктор
> Основной UI-код находится в [frontend/app.js](../../../frontend/app.js).
> Это крупный Vanilla JS-файл, который управляет страницами, настройками, меню и доменными сущностями.
> Дизайн-токены темы определены в [frontend/styles/01-tokens.css](../../../frontend/styles/01-tokens.css).
> Общий CSS подключается из отдельных файлов стилей; Tailwind не подтверждён исходниками.
> API-вызовы фронтенда идут через fetch к `/api`.

## Назначение
Рендер основного приложения: навигация, системные страницы, настройки, страницы/меню, агенты, модели, проекты, задачи, разрешения, модули и интеграции.

## Контракт и структура
- `frontend/app.js` содержит состояние UI, API helper, экранирование HTML и функции рендера.
- `frontend/styles/01-tokens.css` задаёт custom properties для темы, цвета, размеров и статусов.
- Перед изменением проверяй шаблон страницы, делегирование событий и порядок инициализации; файл содержит большой объём legacy-кода.

## Инварианты
- Пользовательские данные, вставляемые в HTML, должны экранироваться или добавляться через DOM API.
- Сохраняй существующий API контракт и схемы сущностей.
- Стили темы должны использовать токены, если они доступны, а не создавать дублирующие значения без необходимости.

## Тесты
Серверная логика API частично покрывается [tests/test_server.py](../../../tests/test_server.py). Автоматизированный browser test suite не обнаружен в текущем каталоге `tests/`.
