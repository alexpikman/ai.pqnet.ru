# Конструктор интерфейса и меню

## Общие настройки

Настройки темы, акцентного цвета, шрифта, размеров, скруглений, ширины боковой панели, отступов рабочей области и шапки хранятся локально в `data/settings.json`. Их использует общий layout, поэтому они применяются к системным и пользовательским страницам.

## Меню

Конфигурация навигации находится в `settings.navigation.menu`. Пункт меню содержит:

- `id` — идентификатор пункта;
- `label` — отображаемое название;
- `icon` — идентификатор иконки;
- `page_id` — целевая страница;
- `visible` — отображать ли пункт;
- `parent_id` — родительский пункт для вложенной структуры.

Изменение меню не меняет идентификатор самой страницы. Это позволяет менять подписи и порядок без нарушения ссылок.
